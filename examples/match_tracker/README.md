# match_tracker

Reference app for stratastax-flutter, on the real bundled contracts of stratastax-contract
(`openapi/platform-v1.yaml`, `openapi/catalog-v1.yaml`).

Hand-written: `stx.yaml`, `stx.tokens.yaml`, `i18n/*.yaml` and the annotated classes in
`lib/features/`. Everything in `lib/gen/` is generated by `stx build`:

| Directory | From |
|---|---|
| `lib/gen/contract` | the OpenAPI contracts: models, codecs, validation, endpoints, scopes |
| `lib/gen/style` | `stx.tokens.yaml` + stx_style defaults |
| `lib/gen/i18n` | `i18n/*.yaml` + stx_i18n framework texts |
| `lib/gen/app` | the annotations: forms, pages, mappers, routes, services, app |

## Demo

```sh
tool/demo.sh   # from the repository root: stub server, stx watch and the app in Chrome
```

Then, at http://localhost:8085:

1. **Sign in.** The stub's identity provider offers three users (or use *Sign in with Google* /
   *GitHub*, which go straight to `player` / `admin`):

   | User | Can |
   |---|---|
   | Ada Admin (`admin`) | everything: *New game* and *New match* |
   | Pim Player (`player`) | record matches; *New game* is not in the navigation |
   | Vera Viewer (`viewer`) | read only: *You don't have access to this page* |

2. **Record a match** as Pim: search a game (*cat* → Catan), *Now*, add two players (*cha*, *bo*),
   mark a winner, *Save*. The stub validates the request against the contract and stores it.
3. **Change something** while it runs: a text in `i18n/nl.yaml`, a rule in
   `@UiFieldValidate`, a colour in `stx.tokens.yaml`. `stx watch` regenerates only what changed;
   press `r` for a hot reload.
4. **Look inside**: `dart run stx_compiler:stx scan` prints the merged IR: per form the route,
   the operation and backend it submits to, the scopes the page needs, and per field the contract
   property, the merged rules and the translation keys.

## Commands

```sh
dart run stx_compiler:stx build      # regenerate lib/gen
dart run stx_compiler:stx watch      # … and again on every change
dart run stx_compiler:stx scan       # the merged IR as YAML (--contracts: also the full contract IR)
dart run stx_compiler:stx i18n sync  # add the translation keys new fields need
flutter test                         # incl. end to end against the stub server (test/e2e_test.dart)
```

The base URLs come from `stx.yaml` `backends` and can be overridden with
`--dart-define=STX_PLATFORM_BASE_URL=…` / `STX_CATALOG_BASE_URL=…`; the identity provider with
`--dart-define=STX_OIDC_ISSUER=https://…/realms/stratastax` (e.g. a real Keycloak).

The tokens (`stx.tokens.yaml`) use the shadcn-style stx_style defaults (zinc neutrals, 6px radius,
compact type) with vivid accents: violet primary, blue focus/accent, green success/winner.
